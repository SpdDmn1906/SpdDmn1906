### 🚀 What I do

- **Run production cloud platforms as code** — multi-account AWS managed with Terraform/OpenTofu, plus GKE on the GCP side.
- **Build observability people trust** — Prometheus, Grafana, and CloudWatch with alerting that pages on real problems, not noise.
- **Treat reliability as the product** — my standard is that every incident leaves a guardrail behind.
- **Security-minded by default** — least privilege, drift detection, and posture checks as code.

### 📦 Featured project

**[home_lab](https://github.com/SpdDmn1906/home_lab)** — a production-shaped home datacenter managed entirely as code: OpenTofu + Ansible, Docker and a K3s sidecar cluster, a Prometheus/Grafana/Loki monitoring stack, Tailscale mesh networking, and self-hosted DNS. Where I prototype platform-engineering patterns end to end and document the *why* behind each architectural decision.
